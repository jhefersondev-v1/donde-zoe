# Donde Zoe — versión con imágenes visibles

Esta versión carga las fotos de platos directamente desde Wikimedia Commons, por lo que se ven al abrir el HTML con conexión a internet y también en GitHub Pages.

IMPORTANTE: extrae el ZIP antes de abrir `index.html`. No abras el HTML desde dentro del ZIP.

Para publicar, ejecuta `SUBIR-A-GITHUB.bat`.

## Imagen de marca incluida
La imagen entregada por el usuario se guarda en `img/marca/donde-zoe-mascota.png` y se usa en el encabezado, como sello editorial en "La casa" y en el pie de página.
